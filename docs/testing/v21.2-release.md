## Known validation limitations

`lintDebug` is not clean: 23 errors and 20 warnings remain. Errors consist of
three pre-existing TV manifest declarations (banner, optional touchscreen, and
Leanback support) and 20 untranslated strings, including the new English-only
setup text. The two new API-level errors were fixed before packaging. No lint
baseline or blanket suppression was added. This remains an experimental,
sideloaded debug-variant build, not a Play Store readiness claim.

README and English/Spanish installation instructions now describe the published
guided setup and permanent download URL. Versioned and stable-name APK assets
are byte-identical, with checksums supplied in the release.
